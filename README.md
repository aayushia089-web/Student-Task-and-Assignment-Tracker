## 📖 About The Project

The **Student Task & Assignment Tracker** is a user-friendly productivity project designed to help students organize their academic life efficiently. It allows users to manage assignments, monitor deadlines, track pending tasks, and improve daily productivity with an easy and clean interface.

This project aims to simplify student task management and reduce the chances of missing important submissions. ✨

---

## 🚀 Features

✨ Add and manage assignments  
✨ Track task deadlines easily  
✨ Mark tasks as completed  
✨ Organized and clean user interface  
✨ Helps improve productivity & time management  
✨ Beginner-friendly project structure
